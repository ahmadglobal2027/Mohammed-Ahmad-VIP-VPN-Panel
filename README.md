Mohammad Ahmad VPN Manager

A complete SSH/VPN management suite with a CLI manager and optional web control panel.

🚀 Installation

Run the following command on your VPS as "root":

bash <(curl -fsSL https://raw.githubusercontent.com/ahmadglobal2027/Mohammed-Ahmad-VIP-VPN-Panel/main/install.sh)

The installer requires root privileges.

📋 After Installation

After installation, the manager creates the "menu" command.

Run:

menu

The full manager is also installed at:

/usr/local/bin/naveedghanizada

The installer automatically performs the initial setup and launches the manager when installation finishes.

🌐 Web Control Panel

From the main menu select:

21) Web Control Panel

The web panel can be installed, removed, restarted, and its credentials can be displayed or changed from the Web Control Panel menu.

Panel Port

The web panel uses:

44380/TCP

The installer checks whether the port is available and can open it in UFW/firewalld when required.

After installation, use the credentials generated by the installer to log in.

👤 User Management

The main menu provides:

- Create SSH user
- Delete user
- Renew user
- Lock user
- Unlock user
- Edit user details
- List managed users
- Generate client configuration
- Create trial accounts
- View user bandwidth
- Bulk create users

These options are available directly from the main manager menu.

🔌 VPN & Protocol Management

Supported management options include:

- OpenSSH
- BadVPN / UDPGW
- UDP Custom
- HAProxy Edge
- Nginx Proxy
- DNSTT / SlowDNS
- Falcon Proxy
- ZiVPN
- X-UI / 3X-UI

The installer also provides protocol management, traffic monitoring, and anti-P2P/torrent blocking.

🌐 Free Domain

The manager includes a Free Domain option using deSEC:

Main Menu → 15) Free Domain (deSEC)

It can generate a domain record based on the VPS public IP.

🎨 SSH Banner

The manager supports dynamic SSH login banners showing account information such as:

- Username
- Expiration
- Bandwidth usage
- Daily bandwidth
- Active sessions

📊 Bandwidth Management

The limiter service monitors user sessions and bandwidth usage.

It supports:

- Connection/session limits
- Total bandwidth limits
- Daily bandwidth limits
- Automatic account locking when limits are reached
- Automatic daily reset
- Trial account expiration

The limiter runs as a systemd service.

💾 Backup & Restore

The main menu includes:

18) Backup User Data
19) Restore User Data

Use these options to back up and restore managed user information.

🔄 Auto Reboot

The manager includes:

17) Auto-Reboot Task

This can be configured from the system settings section.

🧹 Cleanup Expired Users

The manager provides:

20) Cleanup Expired Users

Expired accounts can be cleaned from the manager.

🛠️ Web Panel Management

After installing the web panel, the Web Control Panel menu provides:

1) Install Web Panel
2) Uninstall Web Panel
3) Show Panel Credentials
4) Change Panel Credentials
5) Restart Panel Service
0) Back to Main Menu

⚠️ Uninstallation

The manager provides an uninstall option:

99) Uninstall Script

Warning: uninstalling can remove the manager, configuration/user data, limiter services, and other installed components. The script explicitly warns that this action is irreversible.

📌 Quick Start

1. Install

bash <(curl -fsSL https://raw.githubusercontent.com/ahmadglobal2027/Mohammed-Ahmad-VIP-VPN-Panel/main/install.sh)

2. Open manager

menu

3. Install Web Panel

Main Menu → 21 → 1

4. View panel credentials

Main Menu → 21 → 3

5. Restart panel

Main Menu → 21 → 5

🔐 Important

Run the installer only on a VPS/server you control. Review the script before executing it, because it makes system-level changes, installs services, modifies firewall rules, and manages system users.
